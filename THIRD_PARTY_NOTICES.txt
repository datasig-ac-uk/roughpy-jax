Rough Path Primitives (RPP)
==========================

The RoughPy JAX CPU and CUDA extensions use Rough Path Primitives, maintained
by the RoughPy Developers, under the BSD 3-Clause License.

Source repository: https://github.com/datasig-ac-uk/rough-path-primitives

RPP's original copyright notice, license conditions, and disclaimer are
included in third_party/rough_path_primitives/LICENSE.txt in the CPU wheel's
license directory and in the source distribution. CUDA plugin wheels include
the same file under <plugin_package>/licenses/rough_path_primitives/LICENSE.txt.
